# ARTfunny Portfolio Site

Dark-theme multi-page portfolio for cartoon artwork, hosted on **GitHub Pages**.

**Live site:** https://artfunny.uk  
**GitHub Pages URL:** https://Artfunny.github.io/ARTfunny2026/ (redirects to the custom domain)

Until December 2026, **artfunny.co.uk** may still resolve to the older Wix site. Treat **artfunny.uk** as the primary site; the Wix site should point visitors here.

## Pages
- Home, Gallery, Services (+ service detail pages)
- ARToons, Animations, Games, Contact

## Editing
Edit HTML/CSS in this repo (or via the GitHub website) and push to `main`. GitHub Pages updates within a minute or two.

## Domain notes
- Custom domain for this repo is **artfunny.uk** (see `CNAME`).
- After Wix ends (planned Dec 2026), you can point **artfunny.co.uk** at GitHub Pages or keep it as a redirect to `.uk`.
